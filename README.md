# 📊 Technology Usage Behavior Dashboard

### Interactive Data Analytics Using Python and Plotly

## 📌 Project Overview

This project explores technology usage behavior among survey respondents through statistical analysis and interactive data visualization.

The analysis focuses on user age, frequently used devices, purposes of technology usage, daily usage duration, and monthly internet data consumption.

## 🎯 Project Objectives

- Analyze respondents' technology usage behavior.
- Identify the most frequently used devices.
- Explore the main purposes of technology usage.
- Analyze daily technology usage duration.
- Examine monthly internet data consumption.
- Investigate relationships between numerical variables.
- Develop an interactive dashboard using Plotly.

## 📂 Dataset Description

The dataset consists of 55 survey respondents and six original variables.

| Variable | Description |
|---|---|
| ID | Anonymous respondent identifier |
| Frequently Used Devices | Devices commonly used by respondents |
| Purpose of Use | Main purpose of technology usage |
| User Age | Respondent's age |
| Daily Usage Duration | Time spent using technology per day |
| Monthly Data Usage | Monthly internet data consumption in GB |
